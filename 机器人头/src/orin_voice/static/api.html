本地访谈 API

服务地址：http://127.0.0.1:18088 · OpenAPI 3.0 规范

所有写操作使用 Content-Type: application/json。错误返回 JSON：{"error":"原因"}。

方法路径用途
GET/api/status运行状态与当前会话
GET/api/questions简体题目和选项
GET/api/sessions历史会话列表
POST/api/sessions开始访谈，mode 为 voice 或 text
GET/api/sessions/{id}题目、进度、记录、计分与状态
POST/api/sessions/{id}/actionsanswer / repeat / previous / skip / options / stop
GET/api/sessions/{id}/answers.json下载原始 JSON
GET/api/sessions/{id}/summary.txt下载完成总结
GET/api/sessions/{id}/audio/{file}.wav播放或下载回答录音

机器人控制与整包导出

GET /api/robot/status 查看视觉、待机语音、模型与硬件状态。POST /api/robot/actions 的 action 可选 arm、disarm、wake。手动唤醒可传 mode: voice 或 text。

GET /api/sessions/{id}/session_package.json 或 session_package.zip 下载全部21题、结果、对话过程及音频；transcript.json 提供完整对话，full_audio/{file}.wav 提供整场分轨音频。

调用示例

curl http://127.0.0.1:18088/api/sessions \
  -H 'Content-Type: application/json' \
  -d '{"mode":"voice"}'

curl http://127.0.0.1:18088/api/sessions/会话编号/actions \
  -H 'Content-Type: application/json' \
  -d '{"action":"answer","score":2,"question_id":"Q01"}'

curl http://127.0.0.1:18088/api/sessions/会话编号

语音模式的操作先进入音频线程队列，POST 成功表示已接收；轮询 GET 查看保存及题号变化。文字模式同步执行。question_id 用于拒绝题号已变化的旧操作。

同一时间只允许一个访谈。结束后可新建。voice 使用开发板上的音频设备，text 不开启麦克风。按钮或文字作答不会凭空产生录音；只有实际收音的回答才有 WAV。

错误码：400 参数无效，403 非本机或跨站请求，404 资源不存在，409 会话或题目状态冲突。语音设备失败通过会话的 phase=error 和 error 字段报告。
