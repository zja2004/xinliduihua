# 学校工作台的报告、量表与分级规则

学校工作台使用本机账号登录。首次登录材料由部署人员交给相应角色。老师在报告页选择本校已关联学籍的一场访谈，可以查看老师复核报告或下载家长脱敏摘要。没有会话时，先建立学籍并将本校会话关联到学生和学期。

## 四类报告

| 使用者 | 查看方式与内容 |
| --- | --- |
| 心理老师 | 选择一场访谈查看明确选分、缺失项、题单版本和解释限制。另加的获审量表保留逐题选分、计分依据、适龄常模、专家签核材料编号、可信度依据和不确定性。原始访谈资料在受权限限制的会话详情内查阅。 |
| 家长 | 老师点击“下载家长脱敏报告”生成可读文本。仅导出固定题单、可核实的版本、数值、完整性和固定解释，以及附加测评的顺序、总分、获审规则版本指纹和适用的复核等级。老师报告可用同一指纹复核规则版本。姓名、学号、会话编号、日期、班级、原话、自由评语、媒体和联系方式均不在导出字段内。该操作不会自动把文件发送给家长。 |
| 学校 | 心理老师、校长和学校管理员可看本校月报。校长和学校管理员可登记每月心理老师人数、面谈室数与可用工时。校长、学校管理员及专家审校账号不能通过本模块访问老师个案报告。 |
| 教育局 | 通过获准学校的逐月汇总比对实访、排期覆盖、人工预警分布、处置、转介审核和回执进度。可导出本期汇总与基于公开指标的工作建议。账号内必须明确列出授权学校。 |

## 量表由谁提供和签核

1. 基金会或学校实际负责方先提供可使用的题单、版权方、许可范围及文件编号、常模、适用年龄、信效度资料、阈值依据和负责审校的专家或机构。材料保管方保存许可和签字原件。软件记录案号和意见。
2. 学校管理员在“量表与分级规则”中录入新版本，或导入 UTF-8 JSON。可下载填报模板。没有计分依据时，暂不发布。退出页面前应提交草稿。
3. 独立的审校账号核对完整题目、计分方向、年龄范围、分界点、常模来源、授权范围与规则限制，在草稿中提交通过或退回意见，填写签核凭证编号。每个版本只有一项最终审批决定。修订另建版本，过往结果继续使用原版本。
4. 在该版本详情中点击“导出本版本规则与专家评审记录”，保存机构留档文本。导出含题单编号、版本、创建人与时间、授权与依据、正反向题号、总分和维度规则、评审决定与材料编号。待审版本明确显示待审状态。
5. 老师在已关联会话下选择已审量表，逐题录入学生的明确选择。系统核对本次年龄和全部题号，生成可复核结果。相同会话及版本只能填写一份，重复提交相同数据返回已存记录，更换答案不会覆盖原始数据。

内置小学 PRIMARY-21 只记录自述。其分数没有经过验证的分级常模；代码屏蔽内置编号及完整内置题单的改名导入。历史 DASS-21 维持原有计分。MHT 的实际版权、资料与常模需要由基金会或授权方提供。若授权版本要求本软件没有实现的常模换算或计分运算，应先扩展引擎并以授权标准样本核验，再投入使用。学生面部、语调、朗读和开放回答不映射为 MHT 选分。

## 四级分界如何核算

自定义规则适用于按序选项计分。选项从 0 起按顺序编号。正向题取明确选分，反向题取“最高选项分 − 明确选分”。分界点必须来自拟发布量表所附的证据，不随软件提供任何临床示例阈值。

| 项目 | 运算和复核条件 |
| --- | --- |
| 总分 | 对 `total_items` 中的题相加。省略时使用全部题。有未选题、超范围选择或缺少适龄资料时拒绝记录计分。 |
| 维度 | 每个 `dimensions` 对象用 `name` 指定名称，`items` 列出获审题号。可按维度分别提供三个 `cutoffs`。 |
| 有效性 | 可在审定的效度维度配置 `invalid_at_or_above`。达到此下界时保留原分，暂停该份量表所有等级解释。 |
| 四级 | 审校通过的三个整数分界点依次记为 a、b、c。分数小于 a 为“预防”，在 [a,b) 为“关注”，在 [b,c) 为“风险”，大于等于 c 为“高危”。每个区间对应一个规则输出，和老师在预警工作流中确认的等级分开记录。 |
| 仅记录数值 | `cutoffs` 留空数组，记录原分和依据。只有总分或维度自身具有获审分界点时才为该项生成复核等级。 |
| 可信程度与限制 | 审校时录入结论可信程度的实际依据和解释限制，显示在老师报告内。对内置自评只说明当次明确选分的可复核性；项目没有个体结论统计置信度。 |

## 跨校及时间窗

区域账号只能读取被明确授权的学校。共用部署时直接汇总本库数据；各校独立内网部署时由学校签出月报，经约定渠道交付区局后离线验签导入。各校与主管单位负责实际数据治理、授权和交付。区域报告不能检索任何学校的个案。

月份按 UTC 自然月筛选，最多一次查询 36 个月。各校每月分别按学生去重。实访按该月发起、截至查询已经完成的访谈。应访按排期到期月，同一学生当月排期全部完成计入已访。风险分布使用每人当月最高人工确认等级，开放预警尚未人工分级时进入待复核。处置、审核、回执和归档指标反映查询时的状态。资源为学校手工登记的当月数量。

本模块采用每格至少五人的发布门槛。总体过小、人数或互补组仅 1 至 4 人时隐藏，风险分布整组抑制，区域只能相加每校均可公开的单元格。没有数据的月份、小样本或没有合法分母时不显示百分比。界面中的“隐藏／无记录”不能用作零参与或零风险的依据。这些规则降低直接暴露小组的机会；汇总表不包含可回查学生的标识。

## 各校独立设备的离线汇总

1. 各校和区局先约定唯一学校编号。不同学校使用不同编号。学校设备以该编号建学籍、分配账号并积累数据，区局为区域账号配置对应的授权学校清单。
2. 在**学校设备**的项目根目录创建 Ed25519 签名身份。示例学校编号为 `NJ-DEMO-01`。命令只把公钥导出到指定文件，私钥留在该部署 `sessions/.school-signing/`，权限为 0600。再次执行会复用同一身份。若配置了其他数据目录，应将 `--output 实际数据目录` 放在子命令前。

```bash
PYTHONPATH=src .venv/bin/python -m orin_voice.school_exchange keygen \
  --school NJ-DEMO-01 --public-out ./NJ-DEMO-01.pub.pem
```

3. 学校将公钥给区局设备管理员，另行核对学校编号和整段 SHA-256 指纹。**在区局设备**预置可信公钥。把示例中的指纹占位符替换为刚才独立确认的实际值。相同学校的新公钥默认拒绝；只有核实正式轮换后才在该命令末尾加 `--rotate`。

```bash
PYTHONPATH=src .venv/bin/python -m orin_voice.school_exchange trust \
  --school NJ-DEMO-01 --public-key ./NJ-DEMO-01.pub.pem \
  --fingerprint '独立核实的64位十六进制指纹'
```

4. 学校管理员或校长在“学校驾驶舱”选择月份，点击“导出签名汇总包”。区局账号在“教育局区域驾驶舱”展开“导入学校离线汇总”，选择 JSON 并点击“验签并导入”。包内仅有学校代码、签发时间、月份、已经执行小样本处理的统计及非个人资源数量。验签同时核对授权学校、已预置公钥、严格字段白名单、月份和小样本口径。两设备时钟应校准。
5. 区局可从表格核对每月签发时间、导入时间与公钥指纹；导出的汇总报告另含原包摘要。相同包重复导入不重复累计，较新签发的同校同月替换旧统计，旧包不能倒退最新结果。本库已存在本校名册或资源登记时，整校以本库实时数据为准，避免与离线包重复计算。区域未分配授权或尚未建立公钥信任时，系统拒绝接收该校汇总。

## 本地自测

在集成项目根目录运行以下命令。测试在临时目录建立两个虚构学校和独立 SQLite 数据库。

```bash
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -p test_school_reports.py -v
node --check src/orin_voice/static/school_reports.js
```

用例覆盖跨校访问拒绝、独立账号评审、未审无法计分、年龄与有效性校验、原始回答防覆盖、家长导出字段、受限区域及学校指标、资源登记和互补小样本隐藏。离线包用两个临时独立数据库测试真实 Ed25519 签名和验签、拒绝未知来源与篡改、重复导入、较旧包和本地优先。真实的外部许可、专家签章与跨机构授权交付由对应单位核验。
