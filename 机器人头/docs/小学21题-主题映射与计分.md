# 小学一周感受问卷 PRIMARY-21：题单与计分映射

这是一份项目自编试用问卷，使用小学日常语言，保留原项目21题的主题位置。措辞、强度、情境和回答选项均已改变，因此**不是DASS-21、不是其等效译本，不具有原量表的信效度或常模**。目前只供老师审阅自述和讨论，尚不能宣称经验证的小学筛查工具。

题单：`configs/primary21.zh.json`；计分：`src/orin_voice/primary21.py`。

统一回想过去一周，选项为0“没有”、1“偶尔”、2“有时”、3“经常”。所有题目同方向：分数较高只表示本人报告该类困扰出现得更多；没有反向题，不以获得某种分数为目标。不知道或不愿回答可以跳过。

## 第一部分：21题直接计分

| 维度 | 题号 | 原始分 | 均分 |
| --- | --- | --- | --- |
| mood 心情与兴趣 | 3、5、10、13、16、17、21 | 7题直接相加，0–21 | 原始分÷7，0–3 |
| worry 担心与身体感受 | 2、4、7、9、15、19、20 | 7题直接相加，0–21 | 原始分÷7，0–3 |
| tension 紧绷与调节 | 1、6、8、11、12、14、18 | 7题直接相加，0–21 | 原始分÷7，0–3 |

总分为21题直接相加，0–63；总均分为总分÷21，0–3。**不乘二，不借用DASS的分界、常模、疾病名称或严重程度标签**。

只计入唯一题号、状态为`answered`、分值为整数0–3的记录。缺题、跳过、尚未确认、重复题号或无效值都视为缺失。某维度未答齐时，该维度原始分和均分为`null`；总题目未答齐时总分与总均分为`null`。已答齐的其他维度仍可显示，并保留每部分的`coverage={answered,total,ratio}`和缺失题号，不用零填补。

接口：`scores(questions)`返回`instrument=PRIMARY-21`、`complete`、`total_score`、`mean_score`、`total_range`、`coverage`以及`subscales.mood/worry/tension`。维度内有`raw_score`、`mean_score`、`raw_range`、`mean_range`、`complete`、`missing_item_ids`和`coverage`。

## 第二部分：3+1任务之后的三项明确补充自评

固定阅读和三个开放回答保留转写、音视频与原始答案，**不从内容、声音、人脸动作、沉默或模型输出推算分数**。在这些任务之后，额外请本人用同一组0–3选项回答下面三项；回想期仍是过去一周，以免与“此刻心情”混淆。

| ID / key | 补充问题 |
| --- | --- |
| R_MOOD / mood | 再想一想过去一周，你有多少时候心情不太好，或对喜欢的事情提不起兴趣？ |
| R_WORRY / worry | 过去一周，你有多少时候觉得担心或害怕？ |
| R_TENSION / tension | 过去一周，你有多少时候心里紧绷，或不太能放松？ |

`task_scores(ratings)`接受`{mood:2,worry:1,tension:0}`这种已明确选择的结构化映射，或`[{id:"R_MOOD",key:"mood",status:"answered",score:2}, ...]`记录。列表必须是`answered`，值必须是整数0–3；回答文字中的数字或频率词不会被这个接口读取。未明确选分时保持`null`。

第二部分标识为`PRIMARY-TASK-3`。每个维度只有一条本人自评，`raw_score`与`mean_score`都为该条0–3选择；3条齐全时才给总分0–9和总均分0–3。它是“任务后的补充自评”，不是阅读准确度、语言表现或任务心理状态的自动评分。

## 两部分只作描述性并列

`comparison(questionnaire_result,task_result)`按0–3的同方向刻度并列第一部分的每维均分与第二部分的明确单项自评，输出`dimensions.{mood,worry,tension}.{questionnaire_mean,task_rating,difference,comparable}`。`difference=task_rating-questionnaire_mean`；一端缺失时差值为`null`。整体只比较两部分均分，原始总分分别是0–63与0–9，**不将后者乘21伪装成等效总分**。

第一部分每维7题，第二部分每维1题，内容及测量误差不同，尚无等效性证据。差值只是两个自述数值的算术差，不自动划分“一致/不一致”“变好/变坏”“患病/健康”，也不能当成任务产生疗效的前后测。`automatic_consistency_judgment`固定为`false`。

## 选分识别与呈现

`explicit_score(text)`仅识别完整、明确的短选择，如“我选二分”“有时”“三分，经常”。否定、纠正、多个分值或解释性叙述需要澄清，不从“我有3个朋友”“不是二分，是三分”等话语抽数。

给孩子的交互只确认记录和继续提问，不播报总分、高低或好坏判断；老师后台可查看原始分、均分、覆盖率和描述性差值，再结合原始访谈人工了解。任何后续面向小学人群的正式筛查用途、阈值或自动判定都需另行验证与核准。
