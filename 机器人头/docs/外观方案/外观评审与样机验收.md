# 心语头罩外观评审与样机验收

对应原清单第 10 项。候选 A 采用浅青灰圆角罩壳、深色眼窗与侧后维护盖，面向小学访谈场景。本图表达拟议造型与功能开口，图中镜头位置是布局假设。当前状态为设计提案，需项目方选择和机械人员复测后才能确定加工图。[查看三视示意图](机甲头部候选A.svg)

| 设计输入 | 测量或确认方法 | 待填写 |
|---|---|---|
| 外包络 W、H、D，含表面件 | 在中性位标定基准面，测最外缘宽、高、深，附正侧面带尺照片 | 实测 mm、样机编号 |
| 镜头、麦克风、扬声器位置 | 从固定基准面定位光轴、出音孔与拾音孔，测偏移与可用孔径 | 坐标、孔径、相机型号 |
| 眼、嘴、颈和线束包络 | 由熟悉头板的工程人员按本机校准限位检查行程，用无动力样板预留间隙 | 最小余量、最大摆幅、照片 |
| 紧固点、后盖、热区 | 与现有底盘和接口位置核对固定点、工具通道、风道及线缆弯折半径 | 孔位、固定方式、热测条件 |
| 外观与接触面 | 现场比对色板、倒角、表面触感、后盖开启方式；由校方确认教室使用情形 | 选色/材质、确认人、日期 |

## 样机验收记录

| 项目 | 操作和通过条件 | 结果 / 证据 |
|---|---|---|
| 正面形象与整体比例 | 交付正、侧、背与桌面实景照片；与签认外观稿逐项比对，由使用方记录接受或改动项 | 待外观定稿和实物 |
| 眼、嘴、颈和可接触部位 | 在校准范围内先做断电检查，再由工程人员看护通电试验。各可动部件不与外壳或线束干涉，可接触边缘与开口经安全人员检查 | 待样机 |
| 摄像与声音 | 同一光照、同一发言位置装壳前后分别验证目标检测、画面视野、收音及回放，将对比文件关联到验收记录 | 待样机 |
| 散热与检修 | 事先由机械/电气负责人填写热测工况、时长、允许温升与紧固标准；记录负载温度、后盖拆装、走线和检修结果 | 待确认标准与热测 |
| 交付 | 记录受控图纸版本、材料工艺、负责人和样机编号；由设计、机械和使用方签认 | 待实物交付 |
