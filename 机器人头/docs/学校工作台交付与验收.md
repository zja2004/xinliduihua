# 心语学校工作台交付与验收

2026 年 11 月 19 日。本机集成项目位于桌面的“机器人头”，原“心理模型”的 clinic 入口也使用集成项目。在线入口为 [学校工作台](http://127.0.0.1:18088/school) 和 [学生访谈](http://127.0.0.1:18088/)。

## 开始一次有学籍的面访

1. 双击桌面的“心语访谈”即可打开学校工作台。设备登录用户在 sessions/学校工作台-首次登录.txt 读取初始账号。teacher 用于本校个案，school_admin 用于学校设置、资源和账号。两者有各自的随机密码，文件权限为 0600。首次登录可在“账号”修改密码；向不同工作人员分别交付对应账号。
2. 管理员可添加本校老师、审校人或校长账号。老师在“任务与学生档案”登记学号、姓名、班级和学期。同一学校的同一学号可延续到下一学期。同名、旧档案和未登记学号的访谈需要老师明确关联。
3. 老师进入“学期面访计划”，选班级、负责人和到期日，再从学生或排期发起面访。此入口将当前浏览器交给学生并退出教职工身份。需要另开老师工作台持续接收提醒时，使用另一个浏览器配置文件或同设备独立浏览器登录老师账号。
4. 学生回答基本资料、21 题、朗读和三个开放问题，以及三项补充自评。完成后，老师重新登录即可查看报告待办、档案、覆盖率。可以选择已有访谈并明确关联学生和学期。
5. 指定某个浏览器承担人物／语音唤醒的终端展示时，由本校老师登录，从访谈工作台点击“启用人物 / 语音唤醒”。该浏览器获得设备配对凭据。自动开始的访谈仅对配对终端或本校授权老师展示。无摄像头时，仍可从名册进行文字面访。
6. 老师在原始记录页查看该校访谈与媒体。家长只取得老师专门导出的家长版。校长、学校管理员和区局账号使用汇总视图；审校人负责材料审校。

## 逐项交付

| 原编号 | 可在本机验证的交付 | 正式验收所需条件 |
|---|---|---|
| 1 成长档案 | 跨期学号、一页档案、六维证据和三个证据层、时间线、跨学期/学年记录、预警及转介归档。老师可对已关联访谈的三个开放回答点按本机 Psyche 摘录，程序逐字核对，保存来源、待复核状态和人工核查记录。 | 核对真实学籍名册及既有档案关联。结论置信程度来自可见证据或老师确认。 |
| 2 分级与报告 | 专家规则版本及审校留痕，老师个案、家长脱敏导出、学校/区域汇总与教育局视图。 | 真实授权版本、适用年龄/常模、分界依据和独立专家签核；PRIMARY-21 继续仅作自评。 |
| 3 量表库 | 授权题单和维度、选项、反向计分、适用年龄、效度条件、阈值、版本、来源及许可材料索引。老师录入明确选择后依审校版本生成附加量表报告。 | 基金会、版权所有方、专家完成真实交付。MHT 题单、常模、分级及对话测评等效性均未获核验。 |
| 4 预警与转介 | 明确文本线索触发暂停和持久待办。支持人工登记、分级、处置、转介接收方、人工送出、回执和归档。打开的本校老师工作台按秒刷新。 | 由学校演练值守、接单、现实联系和转介。现有提醒需要老师工作台在线，不能保证真人在一秒内收到。 |
| 5 驾驶舱 | 学校概览、风险与处置、面访及转介进度、资源登记、区域月报、校间比较、趋势和数据口径；跨设备可交换验签后的去标识月报。 | 部署真实学校、授权区局访问范围，核对公钥指纹和统计来源。 |
| 6 老师任务中心 | 首页办理预警、排期、报告复核、转介、普通待办。到期日与逾期排期可查。 | 由实际老师确认岗位和分工。 |
| 7 面访组织 | 按班安排学期面访、分派、学生终端引导、报告归档、覆盖率和未完成提醒。 | 登记完整名册后，才能把覆盖率用于管理决策。 |
| 8 场景话术 | 考试焦虑、校园欺凌、亲子冲突、自伤风险四类候选；审校、版本和发布，开场仅调用本校已发布话术，安全旁路优先。 | 校内独立审校人逐一评审。候选材料不代表专家已认可。 |
| 9 科普与课程 | 教师按学龄和主题生成可编辑的草稿，审校发布；离线内容包、课件检索播放、学习记录、按班互动与反馈。附小学四年级一学期 16 周课程草案。 | 教师在“话术与课程”载入试点内容，组织审校、开展真实课堂试点并记录反馈。家长端上线另议。 |
| 10 机甲外观 | 原创候选图、测量记录项和样机验收表。 | 目前仅为方案。需实际尺寸、样机、用方定稿及签收。 |

## 运行、数据与验证

本机服务仅监听回环地址。跨校汇总可从不同设备导出签名包后在区域端导入，无需将个案转录或音视频送到区局。远程管理、多终端内网服务与校方身份系统对接需根据实际部署另作配置。本次启动为当前用户会话的临时 systemd 单元，可用 `systemctl --user status xinyu-school-workbench` 查看。

在项目根目录重新启动应用可执行以下命令。若已有服务在运行，直接打开网页即可。

```bash
bash scripts/web.sh --robot --open-browser --chat-profile psyche --chat-port 18082 --chat-max-tokens 160
```

既有数据保留在 sessions/。升级前的 SQLite 快照位于 .runtime/school-backups/。迁移将本设备原有会话归入初始学校 local，旧会话保持逐场可查。新学校编号、教育局授权范围可由本机管理员用以下命令配置。密码在终端隐藏输入。

```bash
PYTHONPATH=src .venv/bin/python -m orin_voice.school_access --help
PYTHONPATH=src .venv/bin/python -m orin_voice.school_exchange --help
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q
```
