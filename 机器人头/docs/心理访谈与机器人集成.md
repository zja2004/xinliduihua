# 心理访谈与机器人集成

> 2026-11-03 更新：集成网页及机器人默认已切换小学自编 PRIMARY-21；完整流程为基本资料 → 21题 → 固定朗读与3个开放问题 → 3项补充自评 → 老师复核。下文保留的DASS部署信息用于历史／显式专业模式。新题单计分、缺失规则和两份分数对照见 [小学21题-主题映射与计分](小学21题-主题映射与计分.md)。


本次将 `心理模型` 的本地语音访谈与 `机器人头` 已有的 CameraHub、YOLO 人脸检测及串口眼球控制整合为一个入口。集成后端维护在 `机器人头`，`心理模型/scripts/clinic.sh` 调用同一个程序，避免两个项目争用摄像头、麦克风和端口。原来的单独 DASS 程序仍保留。

## 一键启动

在开发板已登录的桌面终端运行，摄像头和 Head Controller 应连接到本机：

```bash
cd ~/Desktop/心理模型
bash scripts/clinic.sh
```

也可在 `机器人头` 中运行同名脚本。默认网页为 `http://127.0.0.1:18088/`，心理老师页面为 `http://127.0.0.1:18088/teacher`。端口已被占用时可以加 `--port 18089`。只查看和测试文字流程可执行 `bash scripts/web.sh --open-browser`。

`clinic.sh` 启动人脸跟随（已有硬件校准配置），点击网页“开始新访谈”才开始会话。需要人物/语音自动唤醒时，在工作台启用待机，或执行 `bash scripts/robot.sh`。眼球按最高置信度的一个可见人脸运动；并非面部身份识别，也没有新增整头/颈部运动控制。

## 会话流程

1. 基本资料：姓名或代号、身高 cm、体重 kg、性别、年龄。可预先填写；未填写的字段会逐项提问。数字支持常见阿拉伯数字和中文数词。姓名/代号需要填写，其余可以说“跳过这题”。
2. 心理访谈：保留原 DASS-21 顺序与零到三分的用户选分；机器人会话可先简短交流，说“开始测评”进入量表。
3. 固定文本阅读：使用用户给定的《北风与太阳》完整文本。
4. 开放问题：昨天如何、最近一周最开心的记忆、最近一周最悲伤的记忆。
5. 保存及老师复核。任务允许分次朗读/补充；停顿只保存分段，完成后说“回答完了”或点击“完成当前任务”。可随时说“结束访谈”。

## 数据和媒体

- `sessions/clinical.sqlite3`：SQLite 资料、会话、任务回答和媒体索引；无须安装 SQL 服务。
- `sessions/<id>/answers.json`：基本资料、DASS 选分、计分、五项资料原始回答、四项任务回答和音频关联。
- `events.jsonl` / `transcript.json`：完整对话和播放状态。
- `audio/*.wav`：逐项原始回答分段；`full_audio/*.wav`：连续麦克风和机器人实际提交到输出设备的音频，分别保存。
- `video/`：共享摄像头录制的视频和录制状态清单。录制不另开摄像头，不与人脸跟随争用设备。
- `session_package.json` / `session_package.zip`：整场结果及媒体。ZIP 在录音和录像关闭之后生成。

老师端显示资料、逐题回答和选分、量表计分、任务文本/回答、全文对话、录音录像播放器、录制错误和原始 JSON。数据和媒体仅向本机开放，目前没有远程老师账号登录；这是一版本地工作站。

录像和录音是独立文件。连续音频包含时间轴，不能把机器人输出紧凑音轨当作已经与录像混流同步的单个视频。摄像头无法打开、编码失败或录音异常时会保留已存回答并显示失败，不能据此声称已完成全程录制。

## 验证范围

自动化覆盖基础语音、量表、共享摄像头/跟随模拟、完整资料任务流程、数据库重复索引和 HTTP 接口。真实麦克风收音、扬声器回放、摄像头全程录像和串口眼球运动仍需在连接硬件的开发板桌面会话验收。
